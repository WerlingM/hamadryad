Full-stack web app for planning and tracking residential landscaping across multiple properties.

**Properties:** Owner's suburban Virginia home (native plant / reduced turf focus) + Richmond, VA rental (larger yard, old-growth trees, veggie garden potential).

**Core features:** Visual yard map (MapLibre), garden bed polygons, shared plant species catalog, per-bed plantings with photos/comments/purchase tracking, irrigation annotation layer, cross-property plant queries, basic auth (username/password).

**Why:** Replaces notebooks and spreadsheets; needs to be shareable within family (wife, daughter) with attributed edits.

**Plan file:** `plan.md` — 9 sprints, map-first build order.
**Concept file:** `concept.md` — full requirements doc.

**How to apply:** Use concept.md and plan.md as ground truth when implementing. Sprint 1–4 is the critical path (foundation → properties → map → beds).
