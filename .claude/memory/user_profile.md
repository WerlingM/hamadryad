Homeowner in suburban Virginia, focused on native plant landscaping and reducing turf grass. Also owns a rental property in Richmond, VA.

**Technical background:** Comfortable with TypeScript, containerized apps (Docker Compose), database migrations (has used Prisma, Liquibase). Prefers Node.js ecosystem. Explicitly does not want Python.

**Development style:** Incremental agile — small complete units of functionality, testable and deployable. Does not want big-bang builds.

**Preferences:**
- Open source / free tools preferred over API-key-dependent paid services
- PostgreSQL as default DB choice; open to alternatives with good reason
- React is fine but open to whatever fits best for the app
